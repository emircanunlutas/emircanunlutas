## Featured project

### [Limitmark](https://github.com/emircanunlutas/limitmark)

Security-first resilience testing platform built around explicit authorization and operational boundaries. The project combines a Next.js application with signed ingress, fail-closed admission control, durable authority state and isolated lifecycle operations.

Its infrastructure and security work includes Cloudflare Workers and Durable Objects, R2-backed lifecycle transport, PostgreSQL persistence, bounded provider integrations, staging IAM verification and extensive automated regression coverage.

**Technologies:** TypeScript · Next.js · React · Cloudflare Workers · Durable Objects · R2 · PostgreSQL · REST APIs
