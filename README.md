## Featured project · [LimitMark](https://github.com/emircanunlutas/limitmark)

**Layered application defense and controlled resilience validation.**

LimitMark explores a defense-plane architecture in which *every layer assumes the layer before it may have failed*. It combines a Next.js application, Cloudflare Workers and Durable Objects, explicit authorization, signed ingress, bounded admission controls, lifecycle isolation, and evidence-oriented test harnesses.

| Engineering focus | What I build and verify |
| --- | --- |
| **Defense in depth** | Independent application-layer controls, fail-closed paths, and explicit provider trust boundaries |
| **Legitimate-user continuity** | Canary workflows, request accounting, false-reject visibility, and recovery observations |
| **Reproducible security research** | Deterministic lab scenarios, historical evidence preservation, regression tests, and clearly scoped claims |
| **Operational safety** | Secret-handling guards, staging checks, least-surprise deployment boundaries, and dependency review |

**Stack:** `TypeScript` · `Next.js` · `React` · `Cloudflare Workers` · `Durable Objects` · `R2` · `PostgreSQL`

[Explore the repository](https://github.com/emircanunlutas/limitmark) · [BA0 layer-diversity reference](https://github.com/emircanunlutas/limitmark/blob/ba0-n2-progression/docs/BA0_LAYER_DIVERSITY.md) · [Security policy](https://github.com/emircanunlutas/limitmark/blob/ba0-n2-progression/SECURITY.md)
